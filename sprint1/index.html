1. Instal·lació del sistema operatiu

En aquest apartat es mostra informació del sistema Ubuntu i es consulten algunes de les configuracions bàsiques de l'ordinador, com ara la informació del sistema, la distribució del teclat i les particions del disc.

Informació del sistema operatiu

A la configuració podem consultar la versió del sistema operatiu, el model de l'ordinador, el processador, la memòria RAM i la capacitat del disc. En aquest cas, el sistema instal·lat és Ubuntu 24.04.5 LTS.

Configuració del teclat

En aquest pas es consulta la configuració del teclat per comprovar quina distribució està seleccionada. És important utilitzar una distribució adequada per poder escriure correctament els caràcters i símbols.

Comprovació del disc i les particions

Amb l'aplicació Discos podem consultar les característiques del disc d'emmagatzematge i veure com està distribuït. A la captura es mostra un disc Kingston d'aproximadament 960 GB.

També s'hi observa una partició EFI, utilitzada habitualment per a l'arrencada del sistema, i una partició amb el sistema de fitxers ext4.

Aquestes comprovacions permeten conèixer la configuració actual del sistema en el qual estem operant.

2. Configuració de xarxa bàsica

La configuració de xarxa és imprescindible per poder actualitzar el sistema i instal·lar programari nou.

  • Comprovar l'adreça IP assignada amb ip a.

    Executem l'ordre ip a al terminal per consultar les interfícies de xarxa i comprovar l'adreça IP assignada al sistema.

  • Configurar una IP estàtica si el servei ho requereix.

    Accedim a la configuració de xarxa, seleccionem la pestanya IPv4 i triem el mètode manual per configurar una adreça IP estàtica.

  • Verificar la connectivitat amb ping.

    Executem l'ordre ping 192.168.0.28 per comprovar que hi ha comunicació amb l'adreça IP indicada. Si rebem respostes, la connectivitat funciona correctament.

↑ Tornar a l'índex

3. Creació d'usuaris i grups

La creació d'usuaris permet que diferents persones tinguin el seu propi compte al sistema. També podem assignar-los contrasenyes i consultar els grups als quals pertanyen.

Crear l'usuari amb useradd

Utilitzem l'ordre sudo useradd -m alumne per crear l'usuari alumne. L'opció -m crea el seu directori personal. Si no apareix cap error, l'ordre s'ha executat.

Assignar una contrasenya amb passwd

Amb l'ordre sudo passwd alumne assignem una contrasenya al nou usuari. El sistema ens demana que l'escrivim dues vegades per confirmar-la.

Comprovar l'usuari amb id

Finalment, executem id alumne per comprovar que l'usuari s'ha creat correctament. L'ordre mostra el seu UID, el GID del grup principal i els grups als quals pertany.

4. Comprovació final

En aquest últim apartat comprovem que les configuracions realitzades durant la pràctica funcionen correctament. Hem revisat la connexió de xarxa i la creació d'un usuari al sistema Ubuntu.

Comprovació de la xarxa

Amb l'ordre ip a podem consultar les interfícies de xarxa i les adreces IP assignades. Després, utilitzem ping 192.168.0.28 per comprovar la comunicació amb l'adreça indicada. Les respostes rebudes confirmen que aquesta comunicació funciona correctament.

Comprovació de l'usuari

Hem creat l'usuari alumne amb l'ordre sudo useradd -m alumne i li hem assignat una contrasenya amb sudo passwd alumne. Finalment, amb id alumne hem comprovat que l'usuari existeix i hem consultat el seu UID, GID i grups.

Resultat final

  • La interfície de xarxa té una adreça IP assignada.
  • La prova de connectivitat amb ping ha rebut respostes.
  • L'usuari alumne s'ha creat correctament.
  • La contrasenya de l'usuari s'ha assignat correctament.

Amb aquestes comprovacions, hem verificat el funcionament de la xarxa i la creació de l'usuari. Queden pendents les altres comprovacions de la pràctica que encara no hàgim fet.
